# Home Dashboard

**Document type:** Official NHB platform feature document
**Applies to:** Any question about the home page, dashboard, home feed, what members see when they log in
**Last updated:** April 2026

## Summary

The Home Dashboard is the first page members see when they log into the NHB platform. It surfaces what's happening now: upcoming live calls, recent Library additions, forum activity, updates from coaches, Fast Feedback responses, Hot Seat bookings, and any platform announcements the member needs to see.

The dashboard is designed so that a member who logs in for five minutes to "check NHB" can get oriented quickly — what's live today, what's new, what needs attention.

## What appears on the Home Dashboard

The dashboard typically includes:

- **Upcoming live calls** — the next few scheduled calls the member has access to, with date, time, host, and the option to attend
- **Recent Library additions** — newly added recordings, Fast Feedback responses, and content the member might care about
- **Forum activity** — recent threads and discussions in categories the member follows or has access to
- **Coaching updates** — messages from coaches, program updates, and coach-specific announcements
- **Personal activity** — recent Fast Feedback responses to the member, mentions, and replies to the member's own posts
- **Platform updates** — NHB announcements about new features, changes, or important notices
- **Profile completion card** — if the member hasn't filled in parts of their profile, a prompt to complete it (cosmetic only, not gated)

Content is surfaced based on the member's plan, coaching program enrollment, followed members, and recent engagement patterns.

## Color mode

Members can switch between dark and light color modes through the account settings. This preference persists across sessions.

## Where to find the Home Dashboard

- **Root URL** — the main index page of the NHB platform is the Home Dashboard
- **Home navigation link** — clicking "Home" in the main navigation always returns to the Dashboard

## Related features

- **Live Calls** — upcoming calls surface first on the Dashboard; full schedule lives on the Live Calls page
- **Library** — recent Library additions feed into the Dashboard; full archive is on the Library page
- **Forum** — recent forum activity shows on the Dashboard; full forum is on the Forum page
- **Notifications** — item-level notifications are separate from Dashboard content but complement it

## Summary for answering member questions

When a member asks about the Home Dashboard, the answer should cover:

- What it is: the main landing page members see when they log into NHB
- What appears on it: upcoming live calls, recent Library additions, forum activity, coaching updates, personal activity, platform announcements
- How it is personalized: content is filtered by the member's plan, coaching program, followed members, and recent activity
- Color mode toggle: dark or light mode, configurable in settings
- Where to get to it: the Home link in the main platform navigation, or the root of the NHB platform
