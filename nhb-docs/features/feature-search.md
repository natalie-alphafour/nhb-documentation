# Search

**Document type:** Official NHB platform feature document
**Applies to:** Any question about searching inside NHB, finding content, the search bar, what is searchable
**Last updated:** April 2026

## Summary

Search inside NHB is a full-text search across content the member has access to — Library entries, forum threads, Resources, Fast Feedback submissions, and more. The search is powered by Algolia, which provides fast, fuzzy, typo-tolerant searching across large amounts of content.

## What is searchable

Members can search across:

- **Library content** — live call recordings, Hot Seats, courses, insights, and other archive content
- **Forum threads** — titles, bodies, and comments in categories the member has access to
- **Resources** — templates, swipe files, and other Resource items
- **Fast Feedback submissions** — public Fast Feedback posts and responses
- **Coaches and coaching programs** — finding a specific coach's page or program

The search typically returns results grouped by content type, so members can see matching live calls, matching forum threads, and matching resources as separate result clusters.

## How to search

Members can search in two main ways:

- **Main platform search bar** — usually found in the top navigation, accessible from anywhere on the platform
- **Feature-specific search** — individual features like Fast Feedback, the Library, and the Forum have their own in-context search

Members can search by topic, keyword, coach name, concept, or any other free-text query. The search is typo-tolerant and handles partial matches.

## Plan-gated results

Search only returns content the member has access to based on their plan and coaching program enrollment. Content gated to Fast Forward does not appear in Pro members' search results, and coaching-program-specific content only appears for members of that program.

## Search and MindAI

For members who prefer to ask a question rather than browse search results, MindAI can often answer questions about NHB content without requiring the member to search and read results manually. The two features complement each other:

- **Search** — best when the member wants to browse results themselves and pick the right piece of content
- **MindAI** — best when the member wants a direct answer synthesized from NHB content

## Where to find Search

- **Main navigation** — the search bar typically lives in the top bar of the NHB platform, accessible on every page
- **Within features** — Library, Forum, and Fast Feedback all have their own in-context search

## Related features

- **Library** — uses the platform's search internally
- **Forum** — uses the platform's search internally
- **MindAI** — AI-powered alternative to searching manually
- **Bookmarks** — an alternative to search when members already know what they want and have saved it

## Summary for answering member questions

When a member asks about Search, the answer should cover:

- What it is: full-text search across NHB content the member has access to
- What's searchable: Library entries, forum threads, Resources, Fast Feedback submissions, coaching programs
- How it works: powered by Algolia, fast, typo-tolerant, and fuzzy-matching
- Where to find the search bar: top navigation of the platform, plus feature-specific search within Library, Forum, and Fast Feedback
- Plan gating: search results only include content the member has access to
- When to use MindAI instead: when a direct answer is faster than browsing search results
